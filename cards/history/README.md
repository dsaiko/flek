V aplikaci je nutné **zobrazit informaci o licenci a původu karet** (viz design dokument,
`docs/marias-design.md`). Tyto PNG jsou zdrojové skeny (~960×1536 px); pro web se z nich
vygenerují optimalizované ořezané verze.
